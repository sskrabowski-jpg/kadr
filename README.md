# Кадр

Собственный сервис асинхронных видеосообщений: запись экрана и камеры прямо в браузере → ссылка на видео сразу после остановки.

## Что умеет (MVP)

- **Три режима записи:** экран + камера (кружок вшивается в видео), только экран, только камера.
- **Звук:** микрофон и звук вкладки/системы смешиваются в одну дорожку.
- **Управление записью:** обратный отсчёт, пауза, отмена, перемещение или скрытие кружка камеры прямо во время записи.
- **Мгновенная ссылка:** видео загружается кусками *во время* записи, поэтому после «Готово» почти нечего догружать. Ссылка сразу копируется в буфер обмена.
- **Обработка на сервере:** ffmpeg перекодирует запись в H.264/AAC MP4 (перемотка и Safari работают) и делает превью.
- **Страница просмотра** `/v/:id`: плеер со скоростями 1–2×, счётчик просмотров, скачивание; владелец может переименовать и удалить видео.
- **Библиотека** своих видео.

Аккаунтов пока нет: браузер получает случайный ключ владельца (в `localStorage`), и только с этим ключом можно видеть список, переименовывать и удалять свои видео. Смотреть по ссылке может кто угодно.

## Запуск

Нужны Node.js 22.5+ и ffmpeg (без ffmpeg тоже работает, но видео отдаётся в исходном WebM и без превью).

```bash
npm install
npm run dev        # http://localhost:5173 (API на :3000)
```

Продакшен:

```bash
npm run build
npm start          # http://localhost:3000
```

Или в Docker:

```bash
docker build -t kadr .
docker run -p 3000:3000 -v kadr-data:/data kadr
```

Запись экрана в браузере работает только по **HTTPS** (или на `localhost`), поэтому на сервере поставьте перед приложением Caddy/nginx с сертификатом.

Переменные окружения: `PORT` (по умолчанию 3000), `DATA_DIR` (по умолчанию `./data` — там SQLite и файлы видео).

## Устройство

```
src/                 React-клиент (Vite)
  lib/recorder.js    захват экрана/камеры, сведение на canvas, микширование звука
  lib/api.js         API-клиент и загрузчик чанков с повторами
  pages/             Recorder, Watch, Library
server/
  app.js             Express API + раздача медиа с поддержкой Range
  db.js              SQLite (встроенный node:sqlite)
  media.js           ffmpeg: перекодирование, превью, очередь задач
```

API:

| Метод | Путь | Что делает |
|---|---|---|
| `POST` | `/api/videos` | создать запись (до начала съёмки) |
| `POST` | `/api/videos/:id/chunks?seq=N` | дописать кусок (строго по порядку, повтор безопасен) |
| `POST` | `/api/videos/:id/finish` | закончить и поставить в обработку |
| `GET` | `/api/videos` | мои видео |
| `GET` | `/api/videos/:id` | метаданные (публично) |
| `PATCH` / `DELETE` | `/api/videos/:id` | переименовать / удалить (только владелец) |
| `POST` | `/api/videos/:id/view` | засчитать просмотр |
| `GET` | `/media/:id/video.mp4`, `/media/:id/thumb.jpg` | файлы |

Владелец передаётся заголовком `X-Owner-Key`.
